# Desafio Backend Itaú - Tentativa de Solução

Este repositório contém **minha tentativa de solução** para o desafio backend proposto pelo Itaú.

## Tecnologias utilizadas

- Java
- Spring Boot
- Maven
- REST API

## Objetivos

Durante o desenvolvimento busquei aplicar:

- Boas práticas de programação
- Arquitetura em camadas
- Organização e legibilidade do código
- Tratamento adequado de erros(Obs.: Em adamento)
- Código de fácil manutenção

## Sobre a implementação

Como qualquer desafio técnico, existem diversas formas de resolver o problema. Esta implementação representa **uma das possíveis soluções**, baseada na minha interpretação dos requisitos e nas escolhas de arquitetura que considerei mais adequadas.

Algumas decisões podem diferir de outras implementações, e melhorias sempre podem ser realizadas.

## Considerações

Este projeto foi desenvolvido exclusivamente para fins de estudo, prática e demonstração de conhecimentos em desenvolvimento backend utilizando Java e Spring Boot.

Sugestões de melhoria, feedbacks e contribuições são sempre bem-vindos.
